# FoodAPP: Food ordering app

A simple responsive food website built with React and Tailwind CSS.<br>
Backend is finally done haha

## Features

- Browse food items
- Filter food by category and price
- Search foods by name
- View products details
- Add products to cart
- Increase/decrease cart quantity
- Remove products from cart
- Cart item count
- Responsive design

## Technologies

- React
- Tailwind CSS
- React Router
- Redux Toolkit
- React Icons

## Run Locally

```bash
git clone https://github.com/Jenish-Mhrzn/MERN_FoodApp.git
cd Frontend
npm install
npm run dev
```

## Backend

A REST API built with Node.js, Express.js, and MongoDB to manage food products and newsletter subscriptions.

### Features

- Fetch all food products
- Add new food products
- Delete food products
- Upload and serve food images
- Manage newsletter subscriptions

### Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- dotenv
- CORS

### Run Locally

```bash
cd Backend
npm install
npm start
```
